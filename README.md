# 科技研学演示编排器

本仓库记录该项目已确认的领域对象、事件名称和基础校验方式，便于不同系统交换一致的数据。

## 资料范围

- `docs/orchestration-design.md`：深圳科技研学接待动态编排服务的完整设计（上下文、事件目录、重排规则、可见性矩阵）。
- `contracts/domain.schema.json`：领域事件信封、聚合类型与事件名称。
- `data/sample.json`、`data/sample-itinerary-revised.json`：用于本地联调的中文样例。
- `src/`：事件信封校验（`validator.js`）、行程重排器（`replan.js`）、多语种变更原因目录（`reasons.js`）。
- `tests/`：验证样例符合基础约定，并覆盖重排三核对（转场、退款、拆团）。

当前资料覆盖团队画像、动态时段、当日许可、设备与操作员、逐人准入、拍摄权限、跨境付款、商品领取、替代项目与行程修订。记录一经接收，标识、发生时间与版本不得原地改写；更正使用新的后继记录。个人、机构及商业敏感信息仅向履行职责所需的调用方开放。
